# Embellish the Text: A Pretext Demo Tool
Mini design tool to demo pretext.js library capabilities.

## Description

A mini design tool as a one-page website. Draw and paste images over text; drag and scale what you've drawn around the canvas; and watch how text reshapes dynamically around all your doodles.

The desired feeling of using this interface is book-ish, cosy and crafty; recalling doodling over your notes in class. As a tool, lying somewhere between a whiteboarding design tool and a live magazine editorial design tool.

Most websites and UIs have similar grid or column-based layouts. This is largely due to technical constraints. This project asks: what if text on UI could behave in more dynamic and playful ways, just like doodling over your notes?

### Features

- Brush tool: Draw something on the canvas and watch how text flows around it dynamically. Choose between five gradient brushes, and change the size of brush strokes.

- Sticker tool: Add an image to the canvas, from a selection of 3 contemporary art paintings. (Credits below.) Change the size of the paintings.

- Transform tool: Move and scale anything you've added to the canvas (brush/stickers.) Each doodle is draggable and can change size.

- Theme swap: Swap between light and dark mode.

- Font swap: Change the fonts for text between a selection of mono, serif and sans serif.
